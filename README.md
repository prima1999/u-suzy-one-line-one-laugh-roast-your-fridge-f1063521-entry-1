A single-line roast of my own fridge, written for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty. The program writes one line of at most 200 characters to `/output/entry.txt` — a rent-free roommate that hums show tunes at 2 a.m. and still switches its light on to catch me stealing my own leftovers at midnight.

## Run it

```sh
node main.ts
```

This writes the roast line to `/output/entry.txt`. Passing an output path writes there instead:

```sh
node main.ts /tmp/check/entry.txt
```

The program uses only the Node standard library, takes no input, and is fully deterministic: every run writes the exact same bytes.
